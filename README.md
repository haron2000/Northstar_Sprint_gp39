# Northstar Support Deflection MVP

Support deflection app for Northstar Retail Co. Lets customers check order
status and product stock availability without contacting a human agent.

> Full setup instructions (install, migrate, sample data, run, test) will be
> added once the first features land. This is a placeholder from initial
> project scaffolding.

- SQLite
- Django templates + HTML/CSS/JS
